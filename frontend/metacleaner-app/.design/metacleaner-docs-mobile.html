Úvod

Začněte pracovat s Metadoc API

Vítejte v dokumentaci Metadoc API – RESTful rozhraní pro automatizované čištění a správu metadat souborů. API umožňuje nahrávat soubory, odstraňovat citlivá metadata (GPS, EXIF, IPTC) a stahovat vyčištěné verze přímo z vašich aplikací.

Base URL

https://docs.metacleaner.app/v1

Bezpečné čištění

Odstraní GPS, EXIF a IPTC metadata bez poškození kvality souboru.

Asynchronní zpracování

Soubory se zpracovávají na pozadí. Sledujte průběh pomocí job_id.

Dávkové zpracování

Zpracujte více souborů najednou pomocí sessions a file_ids.

Podporované formáty

JPG PNG HEIC WEBP MP4 MOV
1

Nahrajte soubory

Volejte POST /files/upload — získáte file_id pro každý soubor.

2

Spusťte čištění

Volejte POST /files/clean s file_ids — získáte job_id.

3

Sledujte průběh

Volejte GET /jobs/{'{job_id}'}/status dokud stav není completed.

4

Stáhněte výsledek

Volejte GET /files/{'{file_id}'}/download pro stažení vyčištěného souboru.

Limity požadavků (Rate Limiting)

Každý API klíč je omezen na 120 požadavků za minutu. Při překročení vrátí API odpověď 429 Too Many Requests. Limit se resetuje každou minutu.

Autentizace

Zabezpečení přístupu k API pomocí API klíčů

Metadoc API používá autentizaci pomocí Bearer tokenů. Každý požadavek musí obsahovat platný API klíč v HTTP hlavičce Authorization.

Authorization Header

Authorization: Bearer YOUR_API_KEY

Jak získat API klíč

API klíč vygenerujete ve svém účtu v sekci Nastavení → API Klíče. Klíč se zobrazí pouze jednou při vytvoření – uložte jej na bezpečné místo.

curl -X GET \
  "https://docs.metacleaner.app/v1/jobs/job_xyz/status" \
  -H "Authorization: Bearer YOUR_API_KEY"

Nikdy nezahrnujte API klíč přímo do kódu na straně klienta (JavaScript, mobilní aplikace).

Ukládejte klíč jako proměnnou prostředí (ENV) nebo použijte správce tajemství.

Při podezření na kompromitaci klíče jej okamžitě revokujte a vygenerujte nový v nastavení účtu.

Veškerá komunikace probíhá přes HTTPS. Požadavky přes HTTP jsou automaticky odmítnuty.

401 – Neautorizováno

{
"status": "error",
"code": "INVALID_API_KEY",
"message": "API key is invalid"
}

403 – Přístup zakázán

{
"status": "error",
"code": "FORBIDDEN",
"message": "Access denied"
}

Chybové kódy

Přehled všech stavových kódů

Metadoc API používá standardní HTTP stavové kódy. Všechny chybové odpovědi mají konzistentní JSON strukturu s poli status, code a message.

Struktura chybové odpovědi

{
"status": "error",
"code": "ERROR_CODE", // strojový kód
"message": "Human readable message",
"details": { ... } // volitelné
}
2xx

Úspěch

Požadavek zpracován.

4xx

Chyba klienta

Neplatný požadavek.

5xx

Chyba serveru

Interní chyba.

3xx

Přesměrování

Přesměrujte dotaz.

Kompletní přehled chybových kódů

200
OK

Požadavek úspěšný.

202
ACCEPTED

Asynchronní úloha přijata. Sledujte přes /status.

400
BAD_REQUEST

Chybný formát nebo chybějící parametry.

→ Zkontrolujte tělo požadavku.

401
INVALID_API_KEY

Chybějící nebo neplatný API klíč.

→ Ověřte platnost API klíče.

403
FORBIDDEN

Nedostatečná oprávnění pro operaci.

→ Zkontrolujte plán a oprávnění.

404
FILE_NOT_FOUND

Soubor nebo úloha nebyla nalezena.

→ Ověřte file_id nebo job_id.

409
CONFLICT

Soubor již byl zpracován nebo je konflikt.

→ Nahrajte znovu s novým session_id.

413
FILE_TOO_LARGE

Soubor překračuje maximální povolenou velikost.

→ Soubor musí být menší než 500 MB.

415
UNSUPPORTED_FORMAT

Nepodporovaný formát souboru.

→ Použijte JPG, PNG, HEIC, WEBP, MP4 nebo MOV.

422
VALIDATION_ERROR

Neplatné hodnoty parametrů v požadavku.

→ Zkontrolujte typy a hodnoty parametrů.

429
RATE_LIMIT_EXCEEDED

Překročen limit požadavků (120/min).

→ Počkejte na reset nebo zpomalte volání.

500
INTERNAL_ERROR

Neočekávaná interní chyba serveru.

→ Zkuste znovu nebo kontaktujte podporu.

503
SERVICE_UNAVAILABLE

Služba je dočasně nedostupná (údržba).

→ Sledujte status stránku a zkuste znovu.

Doporučená strategie opakování (Retry)

Pro chyby 429 a 5xx doporučujeme exponenciální backoff:

# Čekací doby: 1s → 2s → 4s → 8s → 16s
delay = 2 ** attempt # max 5 pokusů
