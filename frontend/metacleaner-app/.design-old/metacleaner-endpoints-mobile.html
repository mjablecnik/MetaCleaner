Metadoc API
v1.0

Nahraje jeden nebo více souborů. Podporované formáty: JPG, PNG, HEIC, WEBP, MP4, MOV. Max. 500 MB.

Request Headers

Authorization: Bearer YOUR_API_KEY
Content-Type: multipart/form-data

Request Body

files[] File Povinné

Jeden nebo více souborů (max 500 MB)

session_id string Volitelné

ID relace pro seskupení souborů

Příklad (cURL)

curl -X POST \
  "https://docs.metacleaner.app/v1/files/upload" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "files[]=@photo.jpg" \
  -F "session_id=abc123"

200 – Úspěch

{
"status": "success",
"session_id": "abc123",
"file_id": "f_001"
}

413 – Soubor příliš velký

{
"code": "FILE_TOO_LARGE",
"message": "Max 500 MB"
}

Spustí asynchronní čištění metadat. Vrací job_id pro sledování průběhu.

Parametry options

strip_gps boolean true
strip_exif boolean true
strip_iptc boolean true

Request Body (JSON)

{
"session_id": "abc123",
"file_ids": ["f_001", "f_002"],
"options": { "strip_gps": true }
}

202 – Přijato

{
"status": "accepted",
"job_id": "job_xyz"
}

404 – Soubor nenalezen

{
"code": "FILE_NOT_FOUND",
"file_id": "f_002"
}

Vrací aktuální stav úlohy identifikované pomocí job_id. Stav se aktualizuje v reálném čase.

URL Parametry

job_id string

ID úlohy z odpovědi /clean

Možné hodnoty status

pending processing completed failed
