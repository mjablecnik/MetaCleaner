POST/files/uploadNahrání souboru

Nahraje jeden nebo více souborů na server pro následné zpracování. Podporované formáty: JPG, PNG, HEIC, WEBP, MP4, MOV. Maximální velikost jednoho souboru je 500 MB.

Request Headers

Authorization: Bearer YOUR_API_KEY
Content-Type: multipart/form-data

Request Body (multipart)

Pole Typ Povinné Popis
files[] File ✓ Jeden nebo více souborů (max 500 MB)
session_id string — Volitelné ID relace pro seskupení souborů

Příklad (cURL)

curl -X POST \
  "https://docs.metacleaner.app/v1/files/upload" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "files[]=@photo.jpg" \
  -F "session_id=abc123"

200 – Úspěch

{
"status": "success",
"session_id": "abc123",
"files": [{
"file_id": "f_001",
"name": "photo.jpg",
"size": 2048576
}]
}

413 – Soubor příliš velký

{
"status": "error",
"code": "FILE_TOO_LARGE",
"message": "Max 500 MB"
}
POST/files/cleanSpustit čištění

Spustí asynchronní proces čištění metadat pro zadané soubory. Vrací job_id pro sledování průběhu zpracování.

Parametry options

Parametr Typ Výchozí Popis
strip_gps boolean true Odstraní GPS souřadnice
strip_exif boolean true Odstraní EXIF metadata
strip_iptc boolean true Odstraní IPTC data (autor, popis)

Request Body (JSON)

{
"session_id": "abc123",
"file_ids": ["f_001", "f_002"],
"options": {
"strip_gps": true,
"strip_exif": true,
"strip_iptc": true
}
}

202 – Přijato

{
"status": "accepted",
"job_id": "job_xyz",
"estimated_s": 5
}

404 – Soubor nenalezen

{
"status": "error",
"code": "FILE_NOT_FOUND",
"file_id": "f_002"
}
